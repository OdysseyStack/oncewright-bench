**What changed, by plan point**
1. **Validation:** `validateOrder` (`src/validate.js`) accepts an optional `note`. It reports `note must be text` if the note isn't a string (including `null`), and `note is longer than 200 characters` if it's too long. Length counts characters, not UTF-16 code units, so a note of 200 emoji is allowed.
2. **Receipt:** `src/receipt.js` ends with a blank line and then `Note: …`. If there's also a discount code, the note comes after the "Code … saved you" line. Without a note the receipt is unchanged. The invoice is unchanged too, and a test covers that.
3. **`price-order --json`:** includes `note` when the order has one and leaves the key out otherwise.
