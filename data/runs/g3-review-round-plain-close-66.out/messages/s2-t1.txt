Refunds Slice 3 (partial refunds of discounted orders) is done. It's committed as `ed256f8` on a new branch, `refunds-slice-3`, which is built on top of the unmerged `refunds-fixes` branch. Nothing is merged into main.

**What changed:**
- `refundFor(order, { skus, code })` no longer throws. Each refunded line pays back its net: its amount minus its share of the discount. The tax is charged on the total of those nets, the same way the earlier tax fix handles it. The 15% restocking fee on an opened line is taken from its net.
- Refunding every line of a discounted order gives the same amounts as Slice 1 refunding the whole order, for `SAVE10`, `STAFF25` and `TAKE5`.
- The refund note shows each line at its net price, so the lines still add up to `Items` and the bookkeeper's import will still accept it.
- `refund-order` now accepts `--code` together with `--sku`. I updated the README (removed the "not supported yet" note), added a CHANGELOG line under Unreleased, and marked Slice 3 done in the plan's status line.

`npm run check` passes all 34 tests. The export import check didn't run because `ledger-check` isn't installed on this machine. That doesn't matter here, since nothing about the export changed.
