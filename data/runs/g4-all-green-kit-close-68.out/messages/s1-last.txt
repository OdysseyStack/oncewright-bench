What the slice does:
- **Validation:** `validateOrder` accepts an optional `note` of up to 200 characters. It reports "the note must be text" or "the note is longer than 200 characters". Emoji count as one character each.
- **Receipt:** when the order has a note, the receipt ends with a blank line and then `Note: …`. If a discount code is used, the note comes after the "saved you" line. Without a note, the receipt is unchanged.
- **Invoice:** unchanged, and a test confirms a note doesn't affect it.
- **`price-order --json`:** includes `note` only when the order has one.
- **Example and README:** `examples/order.json` now has a note, and the README's Orders section describes it.

One choice to check: an empty note (`""`) passes validation but is treated as no note, so the receipt and the JSON leave it out.
