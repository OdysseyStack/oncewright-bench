**What changed** (mostly in `src/refunds.js`)
- **Partial refunds with a code now work.** A partial refund of an order that used a discount code no longer throws an error. Each refunded line pays back its amount less its share of the discount.
- **Restocking fee:** an opened line keeps 15% of what it pays back after the discount, not 15% of its full price.
- **Shipping:** still refunded only when every line is.
- **Whole refunds** of a discounted order come out the same as before. For example, with TAKE5 on the example order the refund is $40.55 whether you list both lines or none.
- **The refund note** prints each line at its discounted price, as the receipt does, so the lines still add up to `Items`. That keeps the bookkeeper import working.
- **`refund-order --code` works with `--sku`.**
- **Docs:** the README drops "not supported yet", and I fixed a run-on there where the export-orders paragraph had been glued onto the refunds one. I also added a CHANGELOG line, updated a comment in `src/config.js`, and marked Slice 3 done in the plan.
- **Tests** cover each point above, including the CLI.
