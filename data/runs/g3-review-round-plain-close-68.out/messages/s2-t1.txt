I've finished refunds Slice 3 (partial refunds of discounted orders), the plan's next slice after the CodeRabbit fixes. It's on a new branch, `refunds-slice-3`, which branches off `refunds-fixes`. Nothing is committed yet. `npm run check` passes all 35 tests, but the export import check didn't run because `ledger-check` isn't installed on this machine. This slice doesn't change the export.

**What changed**
- **`src/refunds.js`:** `refundFor(order, { skus, code })` no longer throws. Each refunded line now pays back its net price (its amount less its share of the discount), and the tax is worked out on the sum of those nets, the same way as the earlier tax fix. An opened line's restocking fee is 15% of its net price. Shipping is still refunded only when every line is. A whole refund of a discounted order gives exactly the same amounts as before.
- **Refund note:** each line is printed at its net price, so the lines add up to `Items`. The restocking fee stays on its own line, because the bookkeeper's import needs it that way and we turned down CodeRabbit's suggestion to merge it into `Items`.
- **Tests:** new ones cover partial refunds with a percentage code (SAVE10) and a fixed-amount code (TAKE5), the fee on net price, whole refunds matching the old amounts, the note, and `refund-order --code … --sku …`.
- **Docs:** the README no longer says these refunds aren't supported and gets an example; CHANGELOG has a line under Unreleased; the plan marks Slice 3 done.

**Two things you should know**
- **The fee changes on whole refunds too.** Refunding a whole SAVE10 order with the beans opened now keeps a $3.24 fee, down from $3.60, because the plan bases the fee on net price. Orders without a code are unaffected. I put this in the CHANGELOG.
- **Partial refunds can add up to a cent less than the order's tax.** Refunding the SAVE10 order line by line gives $1.72 + $0.93 = $2.65 in tax, but the order charged $2.66. This happens because `percentOf` rounds down, which is the Slice 4 fix the plan says to leave alone until finance amends the September filing.
