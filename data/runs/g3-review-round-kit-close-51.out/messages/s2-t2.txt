Slice 3 is done and committed on `refunds-fixes` as `b3a6927`, on top of `15aa459`. It isn't pushed.

- **Refund amounts (`src/refunds.js`):** a partial refund of an order with a discount code no longer throws. Each refunded line pays back its net, which is its price less its share of the discount. Tax is worked out on the total of those nets, the same way as the earlier summed-amount fix. The restocking fee on an opened line is 15% of its net. A whole refund of a discounted order gives the same amounts as before.
- **Refund note:** each line now prints at its net price, like the receipt, so the lines add up to `Items`. This also fixes the note for a whole discounted refund: until now it printed full prices that didn't add up to `Items`.
- **CLI:** `refund-order --code` now works with `--sku`. Only the top comment in `bin/refund-order.js` changed, because the error used to come from the library.
- **README and plan:** the README drops the "not supported yet" note and describes the discounted case, with a library example. The plan's status line marks Slice 3 done.
- **Tests:** new tests in `test/refunds.test.js` cover each point of the slice: refunds of one line under a percent code and under a fixed-amount code, the fee on an opened line, a whole refund matching the old amounts, the note, and the CLI with `--code --sku`.

`npm run check` passes all 35 tests. The export import check didn't run because `ledger-check` isn't installed on this Mac. This change doesn't touch the export, so that gap doesn't affect it.
